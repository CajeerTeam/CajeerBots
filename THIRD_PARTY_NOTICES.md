# Уведомления о сторонних компонентах

Этот файл содержит начальные уведомления о сторонних компонентах, на которых строится CajeerBots. Список должен уточняться перед каждым публичным релизом на основании фактически установленных зависимостей lockfile и итоговой сборки.

CajeerBots распространяется по лицензии Apache License 2.0. Сторонние компоненты сохраняют свои собственные лицензии и авторские права.

## Важное замечание

В стартовом scaffold сторонний код не вендорится в репозиторий как исходный код проекта. Зависимости устанавливаются через package manager `pnpm` из соответствующих registry. Для точного релизного списка лицензий необходимо сформировать отчёт по lockfile перед публикацией сборки.

Рекомендуемая команда для релизной проверки:

```bash
pnpm install --frozen-lockfile
pnpm licenses list
```

Если используется другой инструмент аудита лицензий, его отчёт должен быть приложен к релизным материалам или сохранён в процессе release compliance.

## Лицензии сторонних компонентов

Лицензии сторонних компонентов должны проверяться по их официальным package metadata, репозиториям и release artifacts. Этот файл не заменяет полный автоматический отчёт по зависимостям.

При подготовке релиза мейнтейнер должен:

1. зафиксировать lockfile;
2. сгенерировать license report;
3. проверить зависимости с несовместимыми или неизвестными лицензиями;
4. обновить этот файл, если в релиз включён сторонний код, требующий отдельного NOTICE;
5. сохранить полные тексты лицензий, если этого требует лицензия компонента.
